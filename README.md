# Aramazco WP Theme

Lightweight WordPress theme for **Aramazco** (industrial/B2B), designed to be:

- WooCommerce-ready
- Elementor (free) compatible
- Bilingual (EN default + FA) with RTL support
- Fast, maintainable, and update-safe

## Requirements

- WordPress: latest stable (target)
- PHP: 8.1+

## Dev notes

This repository contains a WordPress theme under `wp-content/themes/aramazco/`.
